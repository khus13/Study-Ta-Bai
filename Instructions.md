# Study Ta Bai: How to Open and Set It Up

## 1. What you need

| Item | Required? | Notes |
|---|---|---|
| **JDK 17 or newer** | Yes | Download from adoptium.net (Temurin) or use the JDK bundled with your IDE |
| **An IDE** (IntelliJ IDEA, NetBeans, or Eclipse) | Optional | Easiest way to open and run the project |
| **Maven** | Optional | Only if you want to use `mvn` commands. IDEs usually include it |
| **Anthropic API key** | Only for AI features | Quizzes, flashcards and Wayground AI. The rest of the app works without it |

Check your Java version in a terminal:

```
java -version
javac -version
```

Both should say 17 or higher. If `javac` is not found, you installed a JRE, not a JDK.

## 2. Unzip the project

1. Unzip `studytabai-java-complete.zip`.
2. You get a folder called `studytabai-java`. Everything below happens inside it.

## 3. Choose one way to run it

### Option A: IntelliJ IDEA (recommended)

1. **File → Open** and select the `studytabai-java` folder (the one containing `pom.xml`).
2. If asked, choose **Trust Project** and let Maven finish importing (bottom-right progress bar).
3. Set the SDK: **File → Project Structure → Project → SDK** → pick JDK 17+.
4. Open `src/main/java/ph/studytabai/Main.java`.
5. Click the green ▶ next to `main`, then **Run 'Main.main()'**.

### Option B: NetBeans

1. **File → Open Project** and select the `studytabai-java` folder (NetBeans recognizes the Maven project).
2. Right-click the project → **Run**. If asked for the main class, choose `ph.studytabai.Main`.

### Option C: Eclipse

1. **File → Import → Maven → Existing Maven Projects**, then select the folder.
2. Right-click `Main.java` → **Run As → Java Application**.

### Option D: Terminal, no IDE or Maven

Linux or macOS:

```
cd studytabai-java
./run.sh
```

If you get "permission denied", run `chmod +x run.sh` first.

Windows: double-click `run.bat`, or in Command Prompt:

```
cd studytabai-java
run.bat
```

### Option E: Terminal with Maven

```
cd studytabai-java
mvn compile exec:java
```

The window "Study Ta Bai" should open with two buttons: **I'm a teacher** and **I'm a student**.

## 4. Turn on the AI features

The app reads your key from an environment variable. It is never stored in the code or in the data files.

**Windows (PowerShell):**

```
setx ANTHROPIC_API_KEY "your-key-here"
```

Close and reopen your terminal (and restart your IDE) afterwards.

**macOS / Linux:**

```
export ANTHROPIC_API_KEY="your-key-here"
```

To make it permanent, add that line to `~/.bashrc` or `~/.zshrc`.

**In an IDE instead:** edit the Run Configuration for `Main` and add `ANTHROPIC_API_KEY=your-key-here` under *Environment variables*.

Optional: set `ANTHROPIC_MODEL` to use a different model. If you don't, the app uses its default.

If the key is missing, the AI buttons show a message and everything else still works.

## 5. Optional: PDF lesson uploads

TXT and DOCX uploads work out of the box. PDFs need the Apache PDFBox library:

- **Maven or an IDE that imported the `pom.xml`:** nothing to do. It is already listed as a dependency.
- **`run.sh` / `run.bat`:** download these jars from Maven Central and put them in the `lib/` folder: `pdfbox`, `pdfbox-io`, `fontbox`, `commons-logging` (version 3.0.x for the first three).

## 6. Optional: read-aloud and music

- **Windows and macOS:** read-aloud uses the built-in speech engine.
- **Linux:** install one speech tool, for example `sudo apt install espeak-ng`.
- Background music is generated by the app and plays on the teacher's computer.

## 7. First run: try it on one computer

1. Click **I'm a teacher → Create account** (fill in name, email, password of 8+ characters).
2. **Lessons** tab → **Upload lesson…** and pick a TXT, DOCX or PDF file.
3. **Quizzes & flashcards** tab → **New quiz** and add questions, or **Generate from lesson (AI)**.
4. **Run a session** tab → choose the quiz, keep *Live game*, click **Host session**. Note the **host, port and join code**.
5. Start a **second copy** of the app (run it again). Click **I'm a student** and enter:
   - Host: `127.0.0.1`
   - Port: the number shown in the teacher window (default 5050)
   - Join code and a nickname
6. In the teacher window press **Start**. Answer in the student window.
7. **Reports** tab → pick the session to see results and export CSV or PDF.

## 8. Using it in a real classroom

- The teacher's computer and the students' computers must be on the **same Wi-Fi or network**.
- The teacher shares the address shown in the console (for example `192.168.1.20`), the port and the join code.
- If students can't connect, allow Java through the teacher's firewall for that port, or pick another port in the *Network port* box.
- Live play has no encryption, so use a trusted classroom network.

## 9. Where your data is saved

Everything is saved in the `data/` folder next to the app as `.ser` files (accounts, lessons, quizzes, sessions). Back up this folder to keep your work. To use another location, start the app with `-Dstb.data=/path/to/folder`.

## 10. Run the automated tests (optional)

```
./test.sh
```

(Windows users can run the three test classes from their IDE: `ModelTests`, `LogicTests`, and `UiSmokeTest` with the VM option `-Djava.awt.headless=true`.) You should see `ALL ... PASSED` three times.

## 11. Troubleshooting

| Problem | Fix |
|---|---|
| `javac: command not found` | Install a JDK (not just a JRE) and reopen the terminal |
| "release version 17 not supported" or errors about `record`/`switch` | Your Java is older than 17. Install JDK 17+ and select it in the IDE |
| Window text is tiny or huge | **View** menu → Larger text / Smaller text / Reset (or Ctrl + and Ctrl -) |
| "AI is not set up" | Set `ANTHROPIC_API_KEY` (section 4) and restart the app and IDE |
| PDF upload says it needs PDFBox | See section 5 |
| Students get "Could not connect" | Check host, port, firewall, and that the session is still hosted |
| "That nickname is taken" | Each nickname must be unique in a session; pick another |
| App fails to start with a data error | The `.ser` files may be from a different version. Move the `data/` folder aside to start fresh |
| No sound from read-aloud (Linux) | Install `espeak-ng` |

More detail on the design, features, and known limitations is in `README.md`.
